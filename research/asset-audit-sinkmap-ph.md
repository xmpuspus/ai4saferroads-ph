# Asset-extraction audit: sinkmap-ph → ai4saferroads-ph

Source repo: `/Users/xavier/Desktop/sinkmap-ph`
Target build: ADB "AI for Safer Roads" — a Safe-System speed-limit-appropriateness MapLibre map of Metro Manila. Road segments glow by a "Speed Safety Score" (km/h the posted limit exceeds the Safe-System-recommended speed for that segment's function + VRU exposure). Needs: a score-glow layer, a before/after "what the limit should be" slider, layer toggles (schools/markets/population/road-class), a findings rail, a methodology page, an e2e harness, and a Vercel deploy.

This is an extraction audit. No quality critique. Each row = a transplantable asset and the concrete change to make it fit road segments.

Key adaptation that recurs below: sinkmap renders rasters (PNG `type:"image"` overlays + a per-pixel velocity ramp). Your data is **vector road LineStrings** carrying a numeric `score`. So nearly every "image overlay" becomes a `type:"line"` layer with a data-driven `line-color` interpolate expression on the score property. Everything else (slider, toggles, rail, findings.json schema, i18n, diag hooks, e2e harness, serve.py, deploy) transplants almost verbatim.
