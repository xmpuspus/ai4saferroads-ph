# Asset-extraction audit: shake-exposure-ph (lindol.ph) -> ai4saferroads-ph

Source repo: `/Users/xavier/Desktop/shake-exposure-ph` (lindol.ph, MIT-licensed code).
Target build: ADB "AI for Safer Roads" - a Metro Manila Safe-System speed-limit-appropriateness map.
Reuse thesis: REPLICATE-NOT-REPLACE. The existing engine is a generic point-in-polygon exposure JOIN
(features x graded hazard bands) wrapped in a static MapLibre/PMTiles map and a reproducible Python
pipeline. Swap the nouns: **building footprints -> road segments**, **MMI shaking bands -> speed-risk
bands**, **MMI intensity -> Speed Safety Score**. Almost every loader, the join, the tile-glow layer,
the dev server, the vercel config, and the e2e harness transplant with renames only.

## Patterns worth lifting (not single files)

- **Atomic cache writes everywhere** (`.part`/`.tmp` then `.replace()`): every loader (boundaries, footprints, population, points, export) writes to a temp sibling then atomically renames, so an interrupted download is never trusted as a complete cache. Carry this into every road/VRU loader.
- **Aggregate-by-stable-id-never-by-name**: PH municipality and town names repeat across provinces; the whole pipeline joins by `shapeID`/`index_right`. Road names repeat too (every city has a "Rizal Ave") - join segments by OSM/Overture id.
- **shapely.prepare + contains-with-zone-first**: the documented perf trap (`pts.within(zone)` is hours, `shapely.contains(prepared_zone, pts)` is seconds). Use it for every segment-in-band test.
- **Build-time-only GEE; site reads committed JSON**: Earth Engine never runs at request time; the pipeline emits JSON artifacts the static site reads. Keep this - the new map should ship committed `segments.geojson`/score JSON, no live GEE.

## Top 3 highest-leverage transplants

1. **`pipeline/exposure.py` (the JOIN engine).** This IS the replicate-not-replace core. `exposure_by_area()` already counts features-in-graded-hazard-bands per admin polygon; swap building centroids -> segment midpoints and MMI bands -> speed-risk tiers and you have the Speed Safety Score aggregation with zero structural change. Keep `_zone()`/`shapely.prepare`/`contains`.
2. **`pipeline/buildings_layer.py` + the frontend glow block (`web/index.html` L640-657, L1040-1075) + `web/serve.py` + `web/vercel.json`.** The entire static-map-with-glowing-priority-features delivery surface: tag features -> tippecanoe PMTiles -> Vercel-Blob-hosted vector layer color-ramped by score, with the Range dev server and hardened CSP. `fill`->`line`, `mmi`->`score`, done.
3. **`pipeline/facilities.py` (+ `population.py`).** The VRU-exposure engine. The Overpass retry/UA helper and `_osm_points(bbox, tag)` give you schools/markets/transit-station points immediately; population.py's WorldPop rasterize/zonal-sum gives the people-near-segment weight. Together they produce the VRU side of the Safe-System score.
